Platform OverviewThe Logistics Orchestration Platform (LOP) is a web-based, API-first infrastructure layer that connects businesses needing delivery services with logistics providers capable of fulfilling those deliveries. It serves four primary user types — Business Clients, Logistics Providers, End Customers, and Platform Administrators — across a unified, intelligent platform.This document details every functional requirement across all phases of the platform, organized by user portal and functional module.1.1 User PortalsThe platform consists of four distinct web portals, each tailored to a specific user type:PortalPrimary UsersCore PurposeBusiness PortalAgrilink, e-commerce platforms, SMEsRequest deliveries, manage orders, track logistics, access billingProvider PortalBike riders, couriers, transport operatorsReceive delivery jobs, navigate routes, manage earningsCustomer Portal / TrackingEnd recipients / buyersTrack deliveries in real-time, receive notificationsAdmin DashboardLOP internal teamManage the entire platform, users, providers, finance, analytics2. Delivery Orchestration EngineThe Orchestration Engine is the core intelligence layer of LOP. It operates as a backend service but its configuration and monitoring are exposed through the Admin Dashboard.5.1 Provider Matching AlgorithmEligibility filter: online providers, within configurable radius of pickup (default 5 km), vehicle type matches package requirementsScoring matrix: proximity (40%), reliability score (30%), delivery type match (20%), current active load (10%)Configurable scoring weights per delivery type (e.g. cold-chain prioritises vehicle type higher)Fallback radius expansion: if no eligible provider within 5 km, expand to 10 km, then 20 kmManual override: business client or admin can force-assign a specific provider5.2 Routing &amp; NavigationRoute calculation using Google Maps Distance Matrix API or OpenRouteService (ORS)Optimal route suggested to provider (shortest time, not necessarily shortest distance)Multi-stop route optimization for batch deliveries assigned to same providerTraffic-aware routing: real-time traffic data factored into ETARoute re-optimization if provider deviates significantly (geofence alert)5.3 Real-Time Tracking EngineProvider app broadcasts GPS location every 10 seconds while delivery is activeWebSocket-based live map updates pushed to business and customer tracking viewsLocation data encrypted in transit (HTTPS/WSS)Offline handling: buffer GPS pings locally if connectivity drops, sync on reconnectGeofence triggers: automatic status update when provider enters pickup/drop-off radius (150 m)5.4 Dynamic Pricing EngineBase fare calculation: flat base fee + per km rate (configurable by zone and delivery type)Weight surcharge: tiered pricing above base weight threshold (e.g. &gt;5 kg)Surge pricing: automatically applied during high-demand periods or low supply (configurable multiplier, max 2.5×)Surge transparency: businesses notified of surge before confirming orderZone-based pricing: different rates for inter-state vs intra-city vs ruralExpress delivery premium: fixed percentage added on top of standard fareCold-chain surcharge: additional fee for temperature-controlled logisticsAdmin can set custom rates per business client (volume agreements)5.5 Automated Dispatch &amp;
